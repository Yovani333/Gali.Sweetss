# Gali.Sweetss
Sitio web para catálogo y venta de Postres

## Configuración

- WhatsApp, horarios, entrega y métodos de pago: `src/config/business.js`
- Productos, imágenes y precios: `src/data/products.js`
- El valor `price: null` muestra "Precio por confirmar". Para publicar un precio, usa un número en MXN.
